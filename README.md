# Make a Child Happy December

React + Vite + JavaScript campaign website starter.

## Getting started

1. Install Node.js if it is not already installed.
2. Open this folder in VS Code.
3. Open the terminal in VS Code and run:

```bash
npm install
npm run dev
```

4. Open the local URL printed in the terminal (usually http://localhost:5173).

## Project structure

- `src/components/` — reusable page sections and components
- `src/App.jsx` — main page
- `src/index.css` — global styles and Tailwind import
- `public/images/` — campaign images
